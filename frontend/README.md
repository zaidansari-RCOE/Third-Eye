# Legacy / Unused Frontend

This directory is an earlier, alternative frontend prototype for Third Eye.

**It is not the Phase 6 frontend.** The Phase 6 Control Room and Driver HUD
are implemented in `../web/` and that is the directory documented in the
top-level `README.md` and `docs/`.

This directory is kept as-is:

- Not deleted.
- Not merged with `../web/`.
- Not extended with Phase 6 functionality.

If you are looking for the current, supported frontend, use `../web/`.
